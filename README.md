# Jin Hyeok Kim — Research Portfolio

A professional portfolio covering mass spectrometry, proteomics, laboratory automation, and computational workflows.

## Website

Intended GitHub Pages address: https://jinhyeokkim-90.github.io/

The first case study describes Opentrons OT-2 BCA automation, including geometry-aware transfers, controlled flow rates, and condition-specific repeatability results. The article defines the assay metric, its conditions, and its limits.

## Hosting

This repository contains a reviewed static website under docs/. In repository Settings → Pages, select Deploy from a branch, main, and /docs. The entry point is docs/index.html. No server-side dependencies or package installation are needed for hosting.

The private Master CV, raw experimental files, unpublished clinical research, and full protocol source are maintained separately. This repository contains only the public-facing presentation and derived BCA figures/tables selected for this case study.
